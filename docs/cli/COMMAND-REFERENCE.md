## Not exposed (UI-only), with the reason

| IPC command | why |
|---|---|
| `ai_cli_cancel` | pairs with ai_cli_run |
| `ai_cli_run` | streams the agent's output to the UI as events; run the AI CLI directly instead |
| `app_window_set_space` | needs the calling webview's Window; UI-only |
| `browser_pane_open` | needs the calling webview's Window; a pane is placed inside it by the UI |
| `browser_pane_set_bounds` | pane geometry follows the hosting window's layout |
| `check_winget_update` | also sends the app's analytics heartbeat, on a schedule the UI owns |
| `dock_resize` | live drag resize driven by pointer events; use dock_set_size |
| `dock_set_bar_content_width` | layout measurement reported by the bar's own webview |
| `open_spotlight_edit` | hands a workspace from one window to Spotlight's editor; UI handoff |
| `take_spotlight_edit` | Spotlight's side of that handoff queue |
| `take_terminal_run` | Spotlight's side of the run-in-terminal handoff; use spotlight_run_in_terminal |
| `terminal_open` | streams output over the opening webview's IPC Channel; use spotlight_run_in_terminal or run_project_command |
| `unwatch_dir` | pairs with watch_dir |
| `watch_dir` | pushes change events to the calling webview; use `cooldesk watch` for state events |
| `webapp_embed_close` | pairs with webapp_embed_open |
| `webapp_embed_open` | embedded into a CoolDesk window and positioned by its layout; use open_webapp_window |
| `webapp_embed_set_bounds` | needs the calling webview's Window; layout-driven |
